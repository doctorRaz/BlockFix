## Возможности

Основное назначение BlockFix — приведение блоков к заданным правилам.

В проекте реализованы:

- анализ блоков и выбор блоков для обработки;
- нормализация свойств примитивов внутри блоков;
- установка свойств `ByLayer` / `ByBlock`;
- нормализация цвета, типа и веса линий;
- нормализация глобальной ширины полилиний;
- управление масштабами блоков;
- управление возможностью расчленения блоков;
- работа с атрибутами;
- управление аннотативностью блоков;
- перенос штриховок и маскировок назад;
- оконный и командный режимы обработки;
- настройки приложения и положения окон;
- логирование с настройками пользователя.

## Команды nanoCAD

Основные команды:

| Команда | Назначение |
|---|---|
| `drz_block_normalize` | Нормализация блоков в оконном режиме |
| `drz_block_normalize_Win` | Нормализация блоков в командном режиме с окном настроек |
| `-drz_block_normalize` | Нормализация блоков в командном режиме |
| `drz_block_lstInfo` | Информация о командах сборки |
| `drz_block_AllProp_ByBlock` | Все свойства примитивов по блоку |
| `drz_block_AllProp_ByLayer` | Все свойства примитивов по слою |
| `drz_block_LayerZero` | Примитивы блока на слой 0 |
| `drz_block_Color_ByLayer` | Цвет примитивов по слою |
| `drz_block_Color_ByBlock` | Цвет примитивов по блоку |
| `drz_block_Linetype_ByLayer` | Тип линий по слою |
| `drz_block_Linetype_ByBlock` | Тип линий по блоку |
| `drz_block_Lineweight_ByLayer` | Вес линий по слою |
| `drz_block_Lineweight_ByBlock` | Вес линий по блоку |
| `drz_block_LwGlobalWidth` | Нулевая ширина полилиний |
| `drz_block_Scale_Yes` | Одинаковые масштабы блока |
| `drz_block_Scale_No` | Разные масштабы блока |
| `drz_block_Explodable_Yes` | Разрешить расчленение блока |
| `drz_block_Explodable_No` | Запретить расчленение блока |
| `drz_block_HatchBack` | Переместить штриховки назад |
| `drz_block_WipeOutBack` | Переместить маскировки назад |
| `drz_log_on` | Включить логирование |
| `drz_log_off` | Отключить логирование |
| `drz_log_settings` | Настройки логирования |
