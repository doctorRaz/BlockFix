# blockFix — инструкция пользователя

blockFix — набор команд для нормализации, управление свойствами блоков.

## Команды зарегистрированные в меню, панелях, ленте.

|Команда|Название|Описание|
|---|---|---|
|drz_block_normalize|blockFix…|Нормализация блоков, окно|
|-drz_block_normalize|Нормализация блоков, ком строка|Нормализация блоков, командный режим, настройки ком строка|
|drz_block_normalize_Win|Нормализация блоков, ком строка, настройки|Нормализация блоков, командный режим, настройки окно|
|drz_block_HatchBack|Штриховки назад|Штриховки позади всех|
|drz_block_WipeOutBack|Маскировки назад|Маскировки позади всех|
|drz_block_Explodable_Yes|Разрешить расчленение|Разрешить расчленение блока|
|drz_block_Explodable_No|Запретить расчленение|Запретить расчленение блока|
|drz_block_Scale_Yes|Одинаковые масштабы|Одинаковые масштабы блока|
|drz_block_Scale_No|Разные масштабы|Разные масштабы блока|
|drz_block_AllProp_ByBlock|Все свойства по блоку|Все свойства примитивов по блоку|
|drz_block_AllProp_ByLayer|Все свойства по слою|Все свойства примитивов по слою|
|drz_block_Color_ByBlock|Цвет линий по блоку|Цвет линий примитивов по блоку|
|drz_block_Color_ByLayer|Цвет линий по слою|Цвет линий примитивов по слою|
|drz_block_Linetype_ByBlock|Тип линий по блоку|Тип линий примитивов по блоку|
|drz_block_Linetype_ByLayer|Тип линий по слою|Тип линий примитивов по слою|
|drz_block_Lineweight_ByBlock|Вес линий по блоку|Вес линий примитивов по блоку|
|drz_block_Lineweight_ByLayer|Вес линий по слою|Вес линий примитивов по слою|
|drz_block_LayerZero|Примитивы на слой 0|Примитивы блока на слой 0|
|drz_block_LwGlobalWidth|Ширина полилиний 0|Ширина полилиний блока 0|
|drz_block_lstInfo|Команды BlockFix|Информация о доступных командах с описаниями в ком строку|
